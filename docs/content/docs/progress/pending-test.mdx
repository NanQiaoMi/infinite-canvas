# Pending Tests

The current release needs manual verification in these areas:

- 生图并发批次切分与超限自适应（解决 4 张上限 422 报错）验证：
  1. 超过 4 张（如 8 张）生图请求自动切分与汇聚：在 AI 对话或工作台中输入「生成8张可爱猫咪图」，请求自动切分为两个并发批次 `[4, 4]` 派发至后端，控制台与日志中绝不再出现 HTTP 422 `n: Input should be less than or equal to 4` 拒绝报错，前端汇聚展示全部 8 张图片；
  2. 尺寸与长宽比追问继承：在前序已生成图片的会话中，发送「生成8张横屏的」或「来4张竖屏的」，系统自动锁定 16:9 (1536x864) 或 9:16 (864x1536) 规格并继承上一轮完整画面描述，绝不将提示词清空或退化为「横屏的」；
  3. 负面提示词防污染：当输入的提示词中含有 `[负面提示词] 避免文字、水印、LOGO、拼贴画` 时，场景识别引擎优先剥离负面词块，绝不因负面词中的 `LOGO` 误判为「Logo/图标设计」；
  4. 名词后缀保护：输入「拼贴画」「日系插画」「敦煌壁画」「水彩画」等以「画」结尾的专有名词时，提示词清洗引擎完整保留「画」字，绝不再发生截断（如截成「拼贴」）。

- 修复 AI 对话网络重试 setSteps 异常与 AI 自主构图决策验证：
  1. 彻底修复 `setSteps is not defined` 异常：在 `/chat` 对话中，当大模型接口遇到临时网络波动或连接异常触发退避重试时，步骤状态平滑切换为等待重试，绝不再抛出 `ReferenceError: setSteps is not defined` 白屏报错；
  2. 消除死板标签 `【海报设计/视觉封面】`：输入包含海报、封面等词汇的创作指令时，思维链第一步以自然专业的语言展示（如「分析业务用途与视觉定位 · 规划画面构图与参数」），彻底移除生硬死板的括号标签；
  3. AI 主导视觉构图与动态参数返回：在系统提示词与意图指令中赋予大模型视觉总监角色，由 AI 自主分析业务场景、画面构图、色彩层次，并由 AI 智能判定并返回最佳 size（如海报 768x1024、宽屏设计稿 1536x864）与丰富生动的独立方案提示词；
  4. 多方案（如「生成三张设计稿」）告别死板「方案 1」占位词：当用户要求批量或多套设计方案时，系统为各方案智能匹配差异化创意主题（极简现代、潮流视觉、质感光影、创意插画等），在步骤条中清晰展现方案主题与对应画幅（如「方案 1 · 极简现代 · 1536x864」），绝不再向生图模型发送「设计稿，方案 1」等简陋无效占位词。

- 多会话独立隔离（消除交叉污染、步骤外溢与后台丢图）验证：
  1. 后台多会话并发执行不串扰：在会话 A 中发送「生成三张设计稿」，在生成进行中立即点击左侧「最近对话」切换到会话 B，会话 B 页面保持完全干净，绝不渲染会话 A 的思考步骤、正在执行卡片或流式文本；
  2. 切换会话不粗暴中止后台任务：切换到会话 B 后，会话 A 的后台生成任务安全推进，左侧边栏会话 A 标题旁呈现蓝色呼吸灯，指示正在生成中；
  3. 任务完成后精准归属落库：当会话 A 在后台完成全部 3 张设计稿生成后，呼吸灯熄灭；切回会话 A 时，三张设计稿及思考步骤完整呈现，绝无丢图或仅剩用户单行提问的空白现象；
  4. 侧边栏标题精炼防溢出：包含「在画布上批量生成...」「生成png透明图片：...」等长文本的会话，侧边栏自动剥离冗余修饰词，文字单行平滑截断，不再发生字形截断或换行撑破容器。

- 异步任务式队列、排队状态机展示与刷新恢复验证：
  1. HTTP 202 异步任务进入队列：在生图工作台、AI 对话或无限画布中触发图片生成，若后端返回 202 进入队列，UI 状态机自动切换为「排队等待中」，显示前方排队人数与预计等待秒数；
  2. 绘制中平滑进度条：任务出队进入绘制状态时，UI 切换为「正在绘制中」，实时同步服务端真实 progress 进度；
  3. 主动取消排队：在排队或绘制过程中点击「取消任务」按钮，客户端中断轮询并向服务端发送 `DELETE /v1/tasks/{task_id}` 释放排队槽位，且不消耗用户今日额度；
  4. 页面刷新恢复：在任务处于排队或绘制过程中刷新浏览器页面，页面重新加载后自动恢复活跃任务卡片并继续轮询服务端结果，无需重新提交请求；
  5. 向下兼容同步直出：若后端工作在 HTTP 200 同步模式或网关直出，前端立即展示生成图片，无感知平滑过渡。

- 消除生图多轮 ReAct 循环失控、画布助手生命周期锁死与环境工具隔离验证：
  1. 批量多张生图熔断刹车与并发加速：在 AI 对话中输入「再生成一次，共5张」或「生成5张可爱猫咪图」，大模型调用工具生成 5 张后，系统计数命中并注入强结束提示与硬熔断刹车，立即完成并输出总结，绝对不再触发第 2 轮至第 8 轮生图工具死循环；且多张图片采用并发 Promise.all 调度，总耗时从 3~4 分钟降至单次请求耗时；
  2. 画布助手生命周期稳健释放：在画布页面右侧「AI 画布助手」执行批量生图或任意指令后，无论是正常完成还是中途出错，面板的 `running` 与执行态必然可靠重置，输入框和发送按钮立即恢复可用，杜绝永久冻结锁死；
  3. 普通对话系统提示词净化与画布工具自动解包降级：在 `/chat` 普通对话中，系统提示词完全不暴露 `canvas_*` 工具与示例；若模型依然误输出 `canvas_batch_generate_nodes`，运行时底层自动解包为并发 `generate_image`，直接在对话中交付多张图片，不再抛出 `execution_failed: 当前未处于无限画布工程中` 报错。

- 纯场景描述生图意图精准识别与杜绝历史总结卡片复读验证：
  1. 无显式动作词的场景描述生图：输入「山姆·奥特曼、唐纳德·特朗普和埃隆·马斯克在一家繁忙电影院的柜台后面工作」等人物+场所+活动场景描述时，系统精准判定为 `generate_image` 意图并直连启动出图，绝不误判为普通闲聊或要求用户重复解释；
  2. 杜绝前置生图总结卡片复读污染：前序会话中助手生成的「生成成功\n一只软萌的灰白色小猫...」总结卡片被自动识别为模板套话过滤，在后续回合调用模型时绝对不进入历史上下文，杜绝大模型在后续对话中复读上一轮猫咪内容；
  3. 独立新指令隔离旧图历史：在旧生图会话中直接发送全新独立场景时，系统仅采纳当前新输入的场景文本，绝不强行串联或继承上一轮已生成的猫咪等历史提示词。

- 批量生成上限与 12 节点网格排布验证：
  1. 批量数量扩展至 12：在 AI 对话或画布助手中输入「在画布批量生成12张生肖图标」或「生成一套十个奇幻魔法药水图标」，系统能精准识别数量 `12` 或 `10`，并在画布上一次性创建对应数量的图片节点；
  2. 4 列 × 3 行宽屏网格排布：在画布批量创建 10–12 个节点时，布局算法自动采用 4 列网格（如 12 个节点为 4 列 × 3 行），与宽屏视野完美适配，无节点重叠或换行溢出；
  3. 超过 12 张的安全限制：输入「批量生成20张复古街拍」时，系统安全钳制为 12 张执行，防止并发过载与额度意外耗尽；
  4. 独立并发容错：批量创建的多个节点各自独立触发渲染，单个节点失败不影响其余节点完成，并保留独立重试功能。

- 批量生图提示词提炼、防误加表情包场景与设计稿继承验证：
  1. 萌宠生图不误加表情包场景：输入「生成一个大大撒娇的橘猫 不同状态的」，AI 助手不会自动注入「微信表情包」业务场景要求，仅作为高品质萌宠插画/摄影对待，除非用户明确输入「表情包」；
  2. 纯数量与动作指令干净剥离：输入「再生成一次，共5张」，系统精准提取 `batchCount: 5`，并彻底剥离「一次，共5张」等前缀，送入生图接口的提示词绝对不残留「一次，共5张，主角：...」等畸变前缀；
  3. 规避说明元标签污染提示词：当上游模型返回规格清单（主角：... 风格：... 比例：... 五种状态：...）时，提示词提取器严密过滤「主角」「风格」「比例」等元标签，并精准提取出五种具体状态（求抱抱、委屈哭哭、疯狂贴贴、求亲亲、翻肚皮撒娇），动态拼装出 5 个完整且各不相同的生图提示词；
  4. 设计方案无缝延续：上一轮助手生成了 3 个 UI 设计方案并展示了 3 个英文 promptBlocks，下一轮用户输入「生成三张设计稿」，系统直接继承上一轮已写好的 3 个高质量设计稿提示词并发起 3 次图片生成，杜绝退化为泛化占位的「设计稿，方案 1」；
  5. 历史存量画布会话防泄漏：即使浏览器本地存储中存在此前旧版本未标记 scope 的存量会话，启动时通过标题、工具调用与用户指令多维启发式判断，自动将其归入 `canvas` 作用域，彻底从 `/chat` 侧边栏「最近对话」中隐匿；
  6. 批量生图渐进式显现无卡顿：在 `/chat` 连续/批量生成多张图片时，前序已生成的图片卡片持续展示，正在生成的后续图片在下方展示 Waiting 进度，杜绝下一张图开始时前面生成的图片突然闪烁消失或空白等待。

- 续作意图继承、细节叙事识别与推诿拦截兜底：
  1. 续作自动继承上一轮提示词：在生成第一张人物/场景图片后，输入「再生成一个」或「再来一张」，系统自动回溯历史会话提取上一轮的完整提示词并直接执行出图，杜绝因提示词留空导致的执行失败；
  2. 继承并增补微调：输入「换个姿势再来一个」或「不改变她原来的脸，再来一张」，自动精准继承上一轮的提示词并组合微调要求完成出图；

- AI 对话多次生图逻辑与图片显现动画时序优化：
  1. 防止上一轮回答复读：在同一会话中多次连续要求生成图片时（例如生成完海报素材后，再生成赛博朋克猫咪头像），助手应聚焦当前新任务，增强多段落多句命中剥离，绝不再将上一轮的「已生成一张竖版海报素材...」等套话总结作为前缀照抄复读；

  3. 步骤卡片（StepTrail）永远置顶：完成前与完成后，思维链步骤卡片始终统一位于本轮最顶部，图片居中，总结文本置底，杜绝完成瞬间步骤卡片跳跃至图片下方的错位；
  4. 侧边栏标题平滑省略与幽灵会话回收：会话标题使用 `formatSessionTitle` 智能提取主体并平滑拼接省略号，杜绝长标题切字截断；新建空对话未发送内容时自动复用，消除多余「未命名对话」；
