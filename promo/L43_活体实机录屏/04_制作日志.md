## 4. 已实现清单（对照 03 规范）

**舞台与窗口**
- 1920×1080 `#viewport`，等比缩放居中；暖米色墙纸（渐变 + 暗角 + SVG 噪点，**屏幕空间，不随相机缩放**）
- 真实产品窗口：1366×768 设计尺寸 ×1.125 居中；圆角 12px、软阴影、34px 标题栏、三枚去饱和石色圆点、居中「无限画布」
- 应用顶栏 56px：Logo（内联 `logo.svg` 双三角）、「无限画布」、六项导航（AI 对话/我的画布/生图工作台/视频创作台/提示词库/我的资产），当前项下划线高亮
- `/chat` 空态：276px 侧栏（`#f2efe8`）＋品牌行/`agent` chip/新建对话/最近对话/暂无对话/底部模型与额度；主区欢迎徽章、32px 衬线标题「无限画布 Agent」、描述、三条示例行；底部圆角输入框（placeholder、工具行、`⌘K`、额度、发送按钮）

**引擎（可复用于全片）**
- `seek(t)` 确定性渲染：不依赖 `Date.now/performance.now`，同一 t 两次渲染像素与 DOM 完全一致（已实测）
- 相机：`translate + scale`，焦点坐标为 window 设计坐标 → 自动换算舞台坐标；缓动曲线内建
- 锚点测量：`data-anchor` → `offsetParent` 链累加，不受 transform 影响；当前 78 个锚点可测
- HUD：章节胶囊（clip-path 揭开）、字幕胶囊、KeyCastr 键击条、▶▶ 4× 标签、章节擦除条——结构就位，冷开场只用到章节胶囊
- 光标：22×30 SVG 箭头，屏幕坐标，透明度/位置由时间轴驱动
- 音频：WebAudio 全合成；实时调度 + `OfflineAudioContext` 离线渲染（已实测 8s/2ch/44.1k）

**小方（v4 极简版，按用户反馈「不好看，简单一些」重做）**
- 12×12 矩阵、**只有两个颜色**（主体 `#E8703A` / 眼睛 `#241F1B`）；扁宽身体 **10 宽 × 5 高**，四角切 1 格；两条短腿；**无描边、无暗部、无高光、无嘴**（仅开心/挥手时出现 2px 微笑）
- 眼睛是 **1×1 小点**；姿势：idle / blink / look-left/right/up/down / wide / happy / walk-a/b / crouch / jump-up / jump-fall / land / sit / wave / sleep
- 动作：呼吸（72BPM）、眨眼、走路腿交替、起跳-收腿-落地挤压回弹、落地尘土、出生像素块（8→30px 放大 + 三块收拢）、挥手、坐下
- 落位：只站在真实元素顶边（`window-titlebar`、`chat-sidebar-brand`、`chat-welcome-badge`、`chat-welcome-title`）；脚底与锚点严丝合缝（`SPRITE_ROWS = 10`，绘制时按 10 行基线对齐）

**冷开场 S01–S02（0–8s）**
- 0–1.2s：静止墙纸 + 空态 `/chat`，光标不在
- 1.15–2.0s：Logo 内三角的 3 个像素块依次剥落、放大、落向标题栏顶边并拼合（match-cut origin）
- 2.0–3.4s：小方站上标题栏顶边，眨眼、看向窗口，呼吸
- 3.4–5.4s：蓄力 → 跳向侧栏品牌行 → 再跳向欢迎页星芒徽章 → 站在徽章上看标题
- 5.4–6.65s：第三跳落到 diegetic 片名左侧，沿标题上沿向右走
- 6.65–7.2s：在「Agent」右上方挥手两次
- 7.2–7.75s：站定；7.4–7.75s 坐下看光标
- 7.75–8.0s：起立、章节胶囊 `01 它会自己接活` 随擦除揭开
- 光标：2.85–3.3s 从画外弹入 `(1520,940)`；6.2–7.2s 移到输入框右下 `(1180,760)`
- 音效：房间底噪、钟琴 C5、三声像素剥离、落地、boing、脚步、挥手、whoosh、章节 chime

## 6. 与 02/03 的偏差（需 Lead 评审确认）

1. **S01 相机起点**：02 写 `zoom 1.35 / focus (250,110)`；实现为 `1.34 / (500,250) → 1.30 / (560,262)`。原因：按原文构图左侧约 30% 画面为空墙纸且窗口右侧被切；调整后窗口左上角落在画面约 12%/16% 处，构图更接近 L43 参考片。
2. **S02 相机**：02 只写 `1.30/(320,140) → 1.52/(683,300)`；实现为四段跟随（含 4.0–4.6 向左跟随、4.6–5.4 保持、5.4–6.2 向右推近至 `1.50/(860,322)`）。原因：原文焦点会让跳向侧栏的小方出画、且片名不在构图重心。
3. **S02 中间落点**：02 写「描述段上沿」；实现改为「欢迎页星芒徽章顶边」。原因：站在描述段顶边时小方的身体正好压住 diegetic 标题「无限画布 Agent」，违反「小方不挡要读的字」。
4. **出生像素块尺寸**：02 写 8×8 px；实现在下落过程中从 8px 放大到 30px。原因：窗口内 8px 在 1.3 倍推近下几乎不可见，读不出「像素块剥落」。
5. **小方最终站位**：02 写「标题字上方」；实现停在标题右端外侧（`title.right + 24`），挥手时不压「Agent」。
6. **章节胶囊揭示**：02 写 7.75–8.25 擦除；实现一致，因此 8.0s 时胶囊尚未完全揭开（约 87%）。若第 1 幕实现后需要 8.0 完整成形，可将区间改为 7.75–8.0。
7. **文件形态**：开发期 `index.html + film/*.js`（非单文件）；收尾时内联。
8. **小方造型修订（用户反馈「不好看，简单一些」）**：v1（8×8 方头 + 2×2 大眼 + 嘴 + 暗部）→ v2/v3（压扁比例）→ **v4（10×5 两色方块 + 1×1 点眼 + 无嘴，最终采用）**。v4 同步替换了 `preview/` 里的截图。
