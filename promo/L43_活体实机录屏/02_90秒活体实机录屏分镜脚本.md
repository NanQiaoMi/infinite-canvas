## 0. 使用说明与硬性口径

### 0.1 本文件是什么

本文件是这支 90 秒 16:9「L43 活体实机录屏」宣传片的**唯一分镜依据**。它规定每一镜的：镜号、时间码、章节、UI 状态与逐字文案、相机、小方锚点与动作、光标与键击、字幕、转场、声音与制作备注。制作端（人或 AI）照此生成可运行的 `index.html`，03 照此写逐镜提示词。

### 0.2 事实与文案口径（与 01/03 零冲突的前提）

1. **事实来源**：`00_制作简报.md` §0–§5 ＝ 方向与规格基准；仓库实际代码与 `git log` ＝ 事实最终裁决（简报亦写明「有冲突时事实以本文件＋仓库实际代码为准」）。本文件所有 UI 文案、数字、行号均按 **HEAD 941fbca** 实测。
2. **UI 文案白名单**：正片可读 UI 文案只能来自「简报 §1.6 上镜 UI 事实表」＋「简报 §1.6.1 上镜 UI 补充登记」（§1.6.1 只含画布 AI 助手面板与生成诊断面板两块，由 Lead 裁决增补，本文件 §11 逐条回抄）。
3. **白名单之外的渲染边界**：真实产品里存在、但白名单未逐字登记的 chrome（图标、tooltip、10px 小字提示、模型名徽标、诊断弹窗内的统计卡标签与事件列表等）允许按真实产品结构渲染，但**不得进入推近焦点、不得被字幕引用、不得作为卖点**；反过来，**不得发明产品里没有的按钮、标签、快捷键、菜单项**。
4. **用户内容与演示数据**：用户气泡文字、助手回复句、节点名、结果图内容、生成记录缩略图、排队人数/等待秒数、诊断事件条目等属于「演示数据」，可以与文案白名单不同，但必须自洽、可复现、不与产品事实冲突；字幕不引用这些演示数字。
5. **版本口径**：片中不出现具体版本号；需要时统一用 `{{版本号}}` 占位。发布状态一律写「本次更新（开发中）」或 `{{发布状态}}`。不出现上限式、全场景式或保证式表述（例如「对所有场景都适用」「保证每一次都成功」「永久无限制」）。
6. **硬性禁止**：真实截图/录屏贴图、第三方品牌与 Logo、真实用户头像/聊天记录/API Key、其他风格库项目内容、O18 制作线任何素材。

### 0.3 关键定义

- **一镜到底**：全片是同一台「录屏相机」在窗口内的一次连续运动，**同幕内零剪切**；页面切换由**甩镜**（whip-pan，方向性动态模糊只加在未变换的外层）遮蔽；只有**章节交界**允许 `0.5–0.7s` 的像素擦除 / 章节胶囊擦除（L43 §6「cuts only under chapter transitions」）。
- **镜头**：本片中「镜头」＝一个相机节拍 ＋ 一个表演单元（L43 的 shot 定义），不是切换点。30 个镜头连续相接、时间码首尾相接、总长严格 **90.0s**。
- **时间码**：`起–止` 精确到 0.1s（内部按 30fps 帧数计算；1 帧 = 0.0333s）。全片 0.0–90.0s，无空洞、无重叠。
- **数据状态**：03 实现时用一个确定性 state 对象描述每一镜的 UI 数据（页面、可见元素、文案、节点、消息、进度），时间轴事件表切换；同一 `t` 必须得到同一画面。

### 1.3 窗口、相机与像素空间

- 窗口设计尺寸 **1366×768 CSS px（16:9 精确）**；在 1920×1080 画布内等比放大 **×1.125** 并居中 → 屏幕上约 **1536×864**（原点约 `(192,108)`）。窗口内一切 UI 按 1366×768 设计坐标排版。
- 相机＝对 `.stage` 容器的一次 `translate(px) scale(z)` 变换：状态记作 `{zoom, cx, cy}`，`zoom ∈ [1.00, 2.20]`（L43 要求 zoom ≥ 1），`(cx, cy)` 为窗口设计坐标中的取景中心。**任何镜头 zoom 不得小于 1.00**；拉回「整窗」＝ zoom 1.00（窗口完整可见）。
- 相机关键帧用弹簧缓动（默认 `cubic-bezier(.22,1,.36,1)`，过冲 ≤ 4% 后回正）；甩镜 0.35–0.55s；推近 0.7–1.2s；慢漂 8–15% zoom 变化 / 2–4s。
- **深度只用两样**：只虚化「不被阅读的窗格」（rack focus）与暗角聚光（spotlight）；**绝不虚化要读的文字**；动态模糊只在甩镜时加，且只加在未参与 `.stage` 变换的外层 wrapper。
- **DOM 测量**：小方与道具的落位坐标每帧由 `offsetParent` 链累加测量（不受 transform 影响），目标元素统一带 `data-anchor`；禁止手写屏幕坐标。

## 3. 全局约定（30 镜共用）

### 3.1 镜头节奏与时间轴

- 每镜给出 `起–止`（0.1s 精度）、时长（0.1s）、章节胶囊状态、UI 状态、相机、小方、光标/键击、字幕、转场、声音、制作备注。
- 同幕内「无切」：上一镜相机终点＝下一镜相机起点（数值连续），小方动作可跨镜延续（如 S07→S08 的键入），字幕可跨镜停留，但**不得跨章节交界**。
- 章节交界处的擦除视为唯一「切」：擦除区间必须完全覆盖交界时刻（如 28.0 的擦除 = 27.7–28.3）。
- 30fps 量化：所有动作起止时间向上取整到帧（如 8.6s = 第 258 帧）；文档中的 0.1s 时间码在实现时对表 `Math.round(t*30)/30`。

### 3.2 相机写法

每镜相机写成：`起 zoom / 焦点(cx,cy) → 止 zoom / 焦点(cx,cy)`，并注明动作类型（push-in / drift / pull back / whip-pan / follow / rack focus / spotlight）与时长。约定：

- 焦点坐标为**窗口设计坐标**（1366×768，左上原点）；整窗中心 `(683,384)`。
- 每镜 `zoom ≥ 1.00`；推近至 2.20 为止；拉回最低 1.00。
- 同幕内相邻镜头相机数值必须等值衔接；甩镜允许在 0.35–0.55s 内大位移，但 blur 只加在外层。
- 「居中聚焦」等产品内视口变化（画布缩放/平移）是**产品交互**，与电影相机叠加：电影相机跟随产品视口，计算新落点时用「产品视口变换后再测量 DOM」的最终屏幕矩形做锚点。
- 暗角聚光只在 spotlight freeze（S30）与主题切换（S26 短暂）使用。

### 3.3 小方表演与像素纪律

- 像素格：12×12 矩阵；窗口内基础单位 `u = 8px`；屏上尺寸约 96px（zoom 1.0）→ 108px（×1.125）→ 推近时 160–190px。
- 站位：**只站在真实 UI 元素的顶边**（标题上沿、输入框顶边、气泡顶边、卡片顶边、胶囊顶边、节点顶边、按钮顶边、窗口标题栏顶边），脚底与元素上沿对齐，留 2px 像素间隙；每镜写明 `data-anchor`。
- 动作库与时序（30fps 帧）：站立；走路 2 帧循环＋翻转朝向；起跳＝预备下蹲 3 帧 → 起跳拉伸 3 帧 → 收腿 2 帧 → 空中 30–50 帧 → 落地挤压 2 帧 ＋ 回弹 4 帧＋尘土 3–4 粒；眨眼 3 帧（随机间隔 1.4–3.2s，确定性种子）；待机呼吸随 72 BPM 每拍微挤压（0.833s）；睡觉＝闭眼＋Z 像素；被戳/挥手/抱道具/推 各有 3–6 帧预置。
- 眼睛承担表演：中立/左/右/上/下/瞪大/开心/闭眼/眨眼 9 种；每镜写明「看哪里」。
- 纪律：不漂浮、不挡字、不压字幕、不出现手；同一镜头里不出现第二种饱和色（小方的 `#E8703A` 是唯一饱和橙）。

### 3.6 字幕规范与停留公式

- 全片字幕 **9 条**（≤ 12）；每条 ≤ 2 行、每行 ≤ 18 个汉字；同一时刻最多 1 条；不遮被讨论的元素、不压小方；字幕胶囊距画面底 84px、距窗口底 120px。
- 字符计数口径（保守）：汉字＋全角标点各计 1；拉丁字母/数字/`⌘` 各计 1；空格不计。
- 停留时长 `hold = max(1.8s, 字符数 × 0.18s + 0.6s)`；本片 9 条逐条计算见 §5。
- 字幕逐字与停留一旦定稿，03 不得改写标点与断行；`?t=` 定格可逐条核对。

### 3.7 键击 HUD 与光标

- 位置：画面右下，键击胶囊距右 96px、距底 168px；键帽 22×22px、圆角 6px、浅色键帽＋深色字；按下时下沉 1px + 高光。
- 英文/符号键：`⌘` `K` `R` `↵` `↓` `9` `5` 等显示标准键帽。
- **中文键入**：采用 L43 录屏里「上屏字逐字落格」的表现，不显示拼音字母键（避免被误读为英文输入）：每个汉字以 1 个键帽从右侧入场、逐个向左堆叠，间隔＝键入间隔；同一时刻最多 5 个；回车前 2 帧清空。此规则为本片统一处理，03 不得改为显示拼音。
- 点击：光标点击有 6% 推近感 + 1 次波纹（2 帧扩散）；悬停目标有 1px 上浮反馈；**光标从不瞬移**（弹簧路径，甩镜期间可随镜头一起被模糊）。
- 任何用户操作必须在画面中可见（光标路径 / 点击 / 键击 HUD），与产品状态变化一一对应（因果闭合）。

### 3.8 声音层与静音点（总表见 §7）

- 两层：**hi-fi 层**（立式钢琴、低音提琴 pizzicato、刷鼓、钟琴）＝世界；**chiptune 层**（方波/脉冲）＝小方。两层可以交替、对答、合奏。
- 音乐 72 BPM（1 拍 0.833s，1 小节 3.333s）；第 1 幕钢琴＋刷鼓；第 2 幕低音提琴＋鼓加层；第 3 幕鼓组全停（网络异常）→ 成功后更轻地回来；第 4 幕全乐队＋chiptune 合奏；片尾 pad＋回车铃。
- Foley：键盘 thock＋click（力度 ±15% 抖动、人类节奏）、触控板 click、面板 swish、弹层 pop、通知 chime、刷新 whoosh、小方脚步/起跳/落地 8-bit、尘土、睡觉 Z 音。
- **静音点**：53.8–54.4（网络异常出现，降到房间底噪 0.6s）；84.0–84.6（spotlight freeze 前 0.6s，降到底噪）。
- 混音目标 −14 LUFS，峰值 ≤ −1 dBTP；产品名「无限画布」不被音效盖住（承诺句前后错开 foley）。
- 禁止罐头史诗配乐、女声吟唱、TTS、任何真实录音素材（全部合成）。
